# LoveSpace launcher artwork

Generated with the built-in image generation tool. Original RGBA artwork is
`lovespace-icon-source.png`; `lovespace-icon.png` is the cream-backed preview.
Android uses density-specific legacy icons and adaptive foreground/background
layers. Regenerate exports with `python scripts/export-app-icon.py` (Pillow).

## Generation prompt

Use case: logo-brand. Create ONE finished square Android app icon for LoveSpace,
a private app for a couple to share daily life and memories. A distinctive elegant
sculptural emblem: two interlocking softly curved ribbon-like ceramic forms
embracing, together forming a heart silhouette with a subtle small home-shaped
negative space at its center. Not a generic flat heart. Warm rose pink and dusty
rose on luminous ivory, subtle matte glazed ceramic material, precise rounded
edges, restrained soft directional shadow, premium tactile editorial design.
Full-bleed pale warm cream square background, NO rounded outer square drawn into
image (Android will mask it), NO text, NO letters, NO watermark, NO mockup,
NO phone. Single centered strong symbol wholly within central 60 percent safe
region, recognizable at 48 pixels, generous clear space, clean front view.
Output 1024x1024 bitmap suitable as actual launcher artwork.
